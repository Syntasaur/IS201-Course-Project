# IS201 Course Project

مشروع مقرر IS201 — ما زالت فكرة المشروع قيد الاختيار.

هذا المستودع يجهّز الهيكل العام والخطة الأولية فقط. لا توجد وظائف خاصة بمجال   
معين أو قاعدة بيانات نهائية في هذه المرحلة.

## التقنية المبدئية

- Python 3
- SQLite من خلال مكتبة `sqlite3` المدمجة مع Python
- Tkinter كخيار مبدئي لواجهة Windows؛ يمكن تغييره بعد اعتماد متطلبات الواجهة

## التشغيل    

التشغيل المبدئي من جذر المشروع على Windows:

```powershell
python src\course_project\__main__.py
```

في الوقت الحالي، نقطة الدخول تعرض رسالة بأن فكرة المشروع لم تُحدّد بعد.

## هيكل المشروع

```text
docs/                    الخطة والقرارات والتوثيق
src/course_project/      كود التطبيق
  database/              الاتصال ومخطط قاعدة البيانات
  models/                نماذج البيانات
  repositories/          عمليات القراءة والكتابة في SQLite
  services/              قواعد العمل
  ui/                    النوافذ وعناصر الواجهة
  utils/                 أدوات مشتركة صغيرة
tests/                   الاختبارات
data/                    ملفات البيانات المحلية أثناء التطوير (لا تُرفع)
scripts/                 أوامر مساعدة للتطوير والتجهيز
```
